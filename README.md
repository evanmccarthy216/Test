# Snake Game

Simple JavaScript Canvas Snake game — a beginner project you can add to GitHub.

Files added:
- `index.html` — game UI and canvas
- `css/style.css` — minimal styles
- `js/game.js` — game logic

How to run

1. Open `index.html` in your browser (double-click or use a static server).
2. Use the arrow keys to move the snake.

Goals

- Learn DOM, Canvas, and basic game loops
- Practice structuring a small project and committing to GitHub
